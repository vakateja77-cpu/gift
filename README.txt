This folder holds the files you personalize.

PHOTOS
------
Replace photo1.jpg ... photo6.jpg with your own pictures (same filenames
is easiest — just overwrite them). Want more or fewer photos, or different
names? Open script.js, find the `photos` array near the top, and edit the
`src` and `caption` for each entry.

MUSIC
-----
Add an MP3 file here named exactly:
    music.mp3
It will be picked up automatically. To use a different filename, open
script.js and change the `musicFile` constant near the top.

The 6 photoN.jpg files currently in this folder are simple placeholders
so the gallery isn't empty — swap them out for the real thing.
